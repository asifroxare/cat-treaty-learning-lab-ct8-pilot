## Contract blockage

A CT6 `CT6_CONTRACT_BLOCKED` response produces the frozen
`contract_blocked` state and renders only the public structured problem
evidence supplied by CT6. It never creates a partial CT5 result. If a prior
successful result exists, it remains separately labelled **Previous result —
inputs changed**.
